# FoodCheck v2

تطبيق ويب/PWA شخصي لفحص المنتجات الغذائية.

## الجديد
- تقييم منفصل للحرقان، الغازات/الانتفاخ، والدهون المشبعة.
- سجل محلي للمنتجات والتجارب والأعراض.
- استخدام التجارب السابقة كتنبيه شخصي عند فحص المنتج مرة أخرى.
- صورة المنتج والمكونات عند توفرها.
- مسح باركود بالكاميرا في المتصفحات التي تدعم BarcodeDetector، مع إدخال يدوي كبديل.
- يعمل من GitHub Pages ولا يحتاج APK أو دومين مدفوع.

## الخصوصية
السجل والإعدادات محفوظة في localStorage على الجهاز/المتصفح. بيانات المنتجات تُجلب من Open Food Facts.

## تنبيه
FoodCheck أداة إرشادية وليس تطبيقًا طبيًا أو بديلًا عن استشارة مختص.

## تحديث الكاميرا v3
- عرض بث الكاميرا داخل التطبيق مع إطار واضح للباركود وزر إغلاق.
- إغلاق الكاميرا تلقائيًا بعد القراءة.
- تحسين رسائل الخطأ والتوافق مع Chrome.
